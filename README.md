# 💪 Fitness Calorie Tracker

A personal fitness tracking web application designed to help users monitor their daily nutrition, hydration, workouts, and fitness progress.

## ✨ Features

- 🔥 Track daily calories
- 🥩 Track daily protein intake
- 💧 Track daily water intake
- 🍎 Add and delete foods
- 🏋️ Log workouts
- ⚖️ Track weight, sets, and reps
- ⏱️ Built-in workout rest timer
- 📅 Workout history organized by date
- 📊 Weekly workout summary
- 🏆 Personal records
- 🔥 Workout streak tracking
- 📈 Progress bars for daily goals
- 🔄 Daily nutrition reset

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
- Git & GitHub

## 🎯 Daily Goals

The tracker currently uses:

- **2,500 calories**
- **150g protein**
- **128 oz water**

These goals can be changed in the JavaScript code.

## 🚀 How to Use

1. Open the fitness tracker in a web browser.
2. Enter your food, calories, and protein.
3. Track your water intake.
4. Log your workouts with weight, sets, and reps.
5. Use the rest timer between exercises.
6. Check your weekly progress and personal records.
